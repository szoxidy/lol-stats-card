# 卡片设计研究与实施

2026-11-13。目标是可嵌入个人主页的紧凑游戏资料卡，标准550×320、Mini400×120。

## 参考与观察

| 参考 | 学习重点 | 本项目的取舍 |
| --- | --- | --- |

研究资料只用于分析，不打包上游截图、用户资料或上游源码。SVG含foreignObject时不能用不支持该元素的栅格器截图评价其视觉；黑图是渲染能力不足，不是原设计。

## 本轮设计约束

- 基色：葡萄灰`#25212b`、色带`#342d3c`、主文字`#f8f2fb`、玫瑰粉`#f0a0cb`、翡翠绿`#9edfc1`、淡紫`#bfadeb`。
- 字体：Comfortaa用于数字与拉丁字符，中文使用系统无衬线。主名字30–32px，核心数字20–23px，标签9–11px。
- 阅读路径：头像和名字 → 等级与近期概况 → 段位 → 近期数据与最近一局。
- 主视觉为英雄横幅与真实头像；下半部的真实段位徽章和近期胜负轨迹为第二层。边框、阴影和微光只用于区分结构，不用装饰线冒充进度。
- 轻动效为缓慢背景呼吸；逐帧模式保留24帧环境光效；静态和减少动画模式不依赖动画显现内容。
- 550px原尺寸检查主信息，390px页面检查缩放与控件；Mini不复用标准卡片的竖向留白。

```text
┌──────────────────────────────────────────────┐
│ 真实头像   名字 / 标签          英雄横幅      │
│            大区               常用英雄       │
├──────────────────────────────────────────────┤
│ 单双排段位 / LP / 赛季胜负 │ 近期胜率 / KDA  │
│ 灵活段位 / LP / 赛季胜负   │ 真实胜负轨迹   │
│ 常用英雄及场数            │ 最近一局       │
└───────────────────────────────资料时间───────┘
```

## 自检与修订原则

原版的问题是主数字过小、段位区缺少完整的图像锚点、雷达与胜负点阵过于零散、Mini预览留白过大。先解决层级和对齐，不靠增加粒子或更换整页配色掩盖问题。每轮根据实际预览检查，再记录修订；不把测试通过当作审美验收。

## 后续反馈后的取舍

实际审阅指出：色条看起来像进度却不承载进度，20局混合样本被拆成过多指标。最终版本删除所有装饰横条和LP进度条，删除阈值雷达、W/L/模式徽章、单独局数和场均击杀助攻；用真实段位徽章与20场胜负轨迹承担图形职责。

主区左侧展示单双排及灵活的赛季段位、LP、胜负和赛季胜率；右侧展示选中模式的近期胜率、KDA与胜负轨迹。底部展示该模式常用英雄与最近一局，模式参数影响整组近期数据。快照不足20场时显示实际场数和筛选来源。

背景增加武装战姬厄运小姐，使用官方皮肤21016原画，不以截图裁图替代。旗帜和勋章需真实账号资料核验，不填装饰性假数据。

## 模式与布局联动

模式切换同时改变段位区。单双排与灵活排位各使用一个较大的对应段位；全部/排位汇总仍并列两套赛季记录。海克斯、极地、匹配使用左侧三行英雄图标、场数与实际胜率，不展示其他模式段位。Mini同样按模式选择段位，娱乐模式保留模式名与KDA。沿用紫灰底、圆润数字、头像横幅和真实战绩，避免再加装饰进度条。
